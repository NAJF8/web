# موقع الأساس | AL ASAS — الموقع ولوحة التحكم

موقع شركة الأساس للاستضافة مع لوحة تحكم خاصة لإدارة كل شيء دون تعديل الكود: نصوص الأقسام، الخدمات، الخطط والأسعار،
الطلبات والرسائل، الهوية البصرية، الإعدادات، والمستخدمون.

مكتوب بـ PHP عادي وMySQL، بلا أطر عمل ولا مكتبات خارجية ولا Composer ولا Node، ويعمل على أي استضافة cPanel مشتركة.

---

## المتطلبات

| المتطلب | الحد الأدنى |
|---|---|
| PHP | 8.1 أو أحدث |
| قاعدة البيانات | MySQL 8 أو MariaDB 10.4 أو أحدث |
| إضافات PHP | `pdo_mysql`، `mbstring`، `fileinfo`، و`sodium` أو `openssl` |
| الخادم | Apache مع دعم ملفات `.htaccess` (الوضع الافتراضي في cPanel) |
| صلاحيات الكتابة | المجلدان `app/` و`uploads/` |

يفحص المثبّت هذه المتطلبات تلقائياً ويعرض كل بند بالأخضر أو الأحمر.

---

## التثبيت على cPanel خطوة بخطوة

1. **أنشئ قاعدة البيانات:** من cPanel افتح **MySQL® Databases**:
   - في «Create New Database» اكتب اسماً مثل `alasas` (يصبح `cpaneluser_alasas`).
   - في «MySQL Users» أنشئ مستخدماً بكلمة مرور قوية.
   - في «Add User To Database» اربط المستخدم بالقاعدة واختر **ALL PRIVILEGES**.
2. **اختر إصدار PHP:** من **Select PHP Version** (أو MultiPHP Manager) اختر 8.1 أو أحدث، وتأكد من تفعيل الإضافات المذكورة أعلاه.
3. **ارفع الملفات:** ارفع محتويات المجلد كاملاً إلى `public_html/` (أو مجلد فرعي) عبر **File Manager** (ارفع ملف ZIP ثم Extract) أو عبر FTP.
   تأكد من رفع الملفات المخفية التي تبدأ بنقطة (`.htaccess`).
4. **شغّل المثبّت:** افتح `https://دومينك/install/` واتبع المراحل الثلاث:
   1. فحص المتطلبات.
   2. بيانات قاعدة البيانات (المضيف غالباً `localhost`، المنفذ `3306`)، ثم يُختبر الاتصال ويُنشأ الجدول والمحتوى الافتراضي.
   3. حساب المالك (الاسم، اسم المستخدم، البريد، كلمة مرور لا تقل عن 10 أحرف).

   ينشئ المثبّت الملف `app/config.php` (بيانات القاعدة ومفتاح التشفير `APP_KEY`) والملف `install/.lock`، ويرفض العمل مجدداً بعدها.
5. **احذف مجلد `install/` بالكامل** من File Manager بعد نجاح التثبيت.
6. افتح `https://دومينك/admin/login.php` وسجّل الدخول.

> لا تغيّر `APP_KEY` في `app/config.php` بعد التثبيت، وإلا تعذّر فك كلمة مرور SMTP ورمز بوت Telegram المحفوظين (يكفي إدخالهما من جديد).

### الحماية المضمّنة

- `app/` مغلق تماماً أمام المتصفح بملف `.htaccess`، وكل ملف فيه يرفض التشغيل المباشر.
- `uploads/` يقبل الصور فقط (PNG وJPEG وWebP، حتى 2MB، بأسماء عشوائية)، وتنفيذ PHP فيه معطّل. ملفات SVG مرفوضة.
- لوحة التحكم: رمز CSRF في كل نموذج، جلسة تنتهي بعد 30 دقيقة خمول أو 12 ساعة، قفل الحساب 15 دقيقة بعد 5 محاولات خاطئة،
  وقفل الـ IP بعد 20 محاولة خلال 15 دقيقة.
- النماذج العامة: حد 5 إرسالات لكل IP كل 10 دقائق، وحقل مصيدة للروبوتات. السعر يُحسب دائماً من قاعدة البيانات وليس من المتصفح.

### استعادة كلمة مرور المالك المنسية (عبر phpMyAdmin)

إن نسي المالك كلمة مروره ولا يوجد مالك آخر:

1. اختر كلمة مرور مؤقتة جديدة (12 حرفاً على الأقل) وولّد تجزئتها. **لا تستخدم مواقع توليد التجزئة على الإنترنت.**
   - من cPanel ← **Terminal** (إن توفر)، أو على جهازك إن كان PHP مثبتاً، نفّذ:
     `php -r "echo password_hash('كلمة-المرور-المؤقتة', PASSWORD_DEFAULT), PHP_EOL;"`
   - الناتج سطر يبدأ بـ `$2y$`؛ انسخه كاملاً.
2. من cPanel افتح **phpMyAdmin** واختر قاعدة البيانات، ثم تبويب **SQL**، ونفّذ الاستعلام التالي
   بعد وضع التجزئة مكان `ضع_التجزئة_هنا` واسم المستخدم الصحيح بدل `owner`:

```sql
UPDATE admins
SET password_hash = 'ضع_التجزئة_هنا',
    must_change_password = 1,
    failed_attempts = 0,
    locked_until = NULL,
    is_active = 1
WHERE username = 'owner';

DELETE FROM login_attempts WHERE username = 'owner';
```

3. سجّل الدخول بكلمة المرور المؤقتة التي اخترتها، وسيُطلب منك فوراً اختيار كلمة مرور جديدة.
   امسح أمر `php -r` من سجل الطرفية بعد الاستخدام (`history -c`) لأنه يحوي كلمة المرور.

> لا تضع كلمة المرور نفسها في العمود؛ يجب أن تكون تجزئة تبدأ بـ `$2y$`. ولا تحفظ كلمة مرور أو تجزئة ثابتة في هذا الملف أو في المستودع.

## ماذا يدير كل قسم في لوحة التحكم

- **لوحة القيادة:** الطلبات الجديدة، طلبات النطاقات، الرسائل غير المقروءة، عدد الخطط النشطة، مخطط الطلبات اليومية لآخر 30 يوماً، واختصارات.
- **نصوص الأقسام:** كل نص في الصفحة مقسّم حسب القسم، مع عدّاد للأحرف، وروابط القائمة الرئيسية.
- **الخدمات / لماذا الأساس / شريط الأرقام / الشبكة / الأنظمة واللوحات / الأسئلة الشائعة:** إضافة وتعديل وحذف، والترتيب بالسحب
  (أو بأزرار ▲▼ من لوحة المفاتيح)، وزر إظهار/إخفاء يُحفظ فوراً.
- **الخطط والأسعار:** الفئات، والخطط ومواصفاتها، ومعاينة حيّة للبطاقة بالدولار والدينار، ونسخ خطة، وزيادة أو تخفيض كل أسعار فئة بنسبة مئوية،
  وسعر الصرف والتقريب وخصم الدفع السنوي والعملة الافتراضية.
- **طلبات الخطط:** بحث، فلترة بالحالة والفئة والتاريخ، فرز، صفحة تفاصيل فيها تغيير الحالة وملاحظات داخلية ونسخ الهاتف ورابط واتساب برسالة جاهزة،
  وتصدير CSV يفتح بالعربية بشكل صحيح في Excel.
- **النطاقات:** صندوق طلبات التسجيل بالأسلوب نفسه، وتبويب أسعار الامتدادات (‎.iq، ‎.com...).
- **الرسائل:** الوارد والأرشيف، مقروء وغير مقروء، بحث، ورد عبر واتساب أو البريد.
- **الهوية البصرية:** الشعار الداكن والفاتح وأيقونة المتصفح (مع معاينة على الأبيض والأسود)، الألوان الثلاثة مع فاحص تباين يحذّر تحت 4.5:1، والخطوط.
- **الإعدادات العامة:** بيانات التواصل، روابط التواصل الاجتماعي، عنوان ووصف الصفحة مع معاينة نتيجة Google، صورة المشاركة، إظهار الأقسام،
  وضع الصيانة، والإشعارات.
- **سجل النشاط:** كل عملية إنشاء وتعديل وحذف ودخول وتصدير واستيراد، ويُحذف ما مضى عليه 180 يوماً تلقائياً.
- **النسخ الاحتياطي:** تصدير JSON واستيراده مع معاينة ما سيتغير، وتنزيل تفريغ SQL كامل.

كل حفظ في لوحة التحكم يمسح الذاكرة المؤقتة للصفحة العامة فوراً، فيظهر التغيير في الموقع مباشرة.

### وضع الصيانة

من «الإعدادات العامة» ← «الأقسام والصيانة». عند التفعيل يرى الزوار صفحة صيانة برسالتك (برمز HTTP 503 مع `Retry-After`)،
بينما يرى المشرفون المسجّلون الموقع كاملاً مع شريط تنبيه أعلاه.

### الإنتاج الإبداعي (السوشل ميديا، تصوير الإعلانات، التصاميم)

قسم في الصفحة الرئيسية (`#creative`) وصفحة مستقلة على `/creative` (أو `creative.php` إن لم يكن mod_rewrite متاحاً).
يُفعَّل بعد تطبيق الترحيل (انظر `DEPLOY.md`)، ويُدار من مجموعة «الإنتاج الإبداعي» في القائمة الجانبية:

- **خدمات الإنتاج والباقات:** لكل فئة، مع قائمة المخرجات/المزايا، سعر شهري أو لمرة واحدة، «الأكثر طلباً»، ونسخ باقة.
  **الباقات المضافة مع الترحيل أمثلة بأسعار افتراضية؛ عدّلها قبل الإعلان عن القسم.**
- **معرض الأعمال — إضافة عمل:**
  1. «معرض الأعمال» ← «إضافة عمل»، اكتب العنوان واختر الفئة ونوع العمل.
  2. **صور:** اسحب الصور إلى المربع (حتى 30). تُحوَّل تلقائياً إلى WebP بحد 2000 بكسل مع مصغّر 600 بكسل،
     ويُصحَّح اتجاهها وتُحذف بيانات الكاميرا والموقع، ولا يُحتفظ بالأصل. أول صورة هي الغلاف إن لم ترفع غلافاً.
  3. **فيديو MP4:** ارفع غلافاً ثم الفيديو. يُرفع على قطع 1MB لذلك يتجاوز حد الاستضافة، والحد الأقصى 50MB.
     للفيديوهات الأطول استخدم YouTube.
  4. **YouTube / Vimeo:** الصق الرابط فقط؛ يُعرض بمشغّل `youtube-nocookie` ولا يُحمَّل إلا عند ضغط الزائر على تشغيل.
  5. فعّل «مميز» ليظهر في الصفحة الرئيسية (أول 6 أعمال مميزة)، ثم «إضافة إلى المعرض». الترتيب بالسحب في الشبكة.
- **طلبات الإنتاج:** مثل طلبات الخطط (فلترة، حالات، ملاحظات، واتساب برسالة جاهزة، CSV). المرفقات (PDF/صور حتى 3 ملفات × 5MB)
  تُحفظ في `app/storage/briefs/` المحجوب، وتُنزَّل فقط من صفحة الطلب لمن يملك الصلاحية.
- **الإعدادات ← الإنتاج الإبداعي:** إظهار القسم، اسمه، واتساب فريق الإنتاج، بريد إشعاراته (وإلا يُستخدم بريد الإشعارات العام)،
  عنوان ووصف الصفحة، وصورة أو فيديو صامت لواجهتها. الأسئلة الشائعة لها مجموعتان: الاستضافة (الرئيسية) والإنتاج (صفحة الإنتاج).

## الإشعارات

عند وصول طلب خطة أو طلب نطاق أو رسالة تواصل أو طلب إنتاج إبداعي:

1. **بريد إلكتروني** إلى «بريد الإشعارات»، عبر دالة `mail()` في الاستضافة افتراضياً.
2. **SMTP (اختياري):** إن أدخلت خادم SMTP يُرسل البريد عبره (يدعم STARTTLS على 587 وSSL على 465). أنشئ بريداً في cPanel ← Email Accounts،
   واستخدم بياناته (الخادم غالباً `mail.دومينك`). يُنصح بـ SMTP لأن رسائل `mail()` قد تصل إلى البريد المزعج.
3. **Telegram (اختياري):** رسالة فورية إلى هاتفك.

فشل أي إشعار لا يمنع حفظ طلب العميل أبداً؛ يُسجّل الخطأ في `app/logs/error.log`.
استخدم زر **«إرسال إشعار تجريبي»** أسفل صفحة الإعدادات للتأكد بعد الحفظ.
كلمة مرور SMTP ورمز البوت يُخزّنان مشفّرين في قاعدة البيانات ولا يظهران في الصفحة بعد حفظهما.

### إعداد بوت Telegram

1. افتح Telegram وابحث عن **@BotFather**، أرسل `/newbot`، واختر اسماً ومعرّفاً للبوت.
2. سيعطيك BotFather **رمز البوت** بالشكل `123456789:AAF...`؛ انسخه.
3. افتح محادثة مع بوتك الجديد واضغط **Start** وأرسل أي رسالة.
4. للحصول على **معرّف المحادثة (Chat ID):** افتح في المتصفح
   `https://api.telegram.org/bot<رمز_البوت>/getUpdates`
   وابحث عن `"chat":{"id":123456789` — هذا الرقم هو المعرّف.
   - لإرسال الإشعارات إلى مجموعة: أضف البوت إلى المجموعة، أرسل فيها رسالة، وأعد فتح الرابط؛ معرّف المجموعة يبدأ بـ `-`.
5. ضع الرمز والمعرّف في «الإعدادات العامة» ← «الإشعارات» واحفظ، ثم اضغط «إرسال إشعار تجريبي».

## النسخ الاحتياطي

- **تفريغ SQL (الأهم):** من «النسخ الاحتياطي» ← «تنزيل ملف SQL». يحتوي كل الجداول بما فيها الطلبات والمستخدمين، ويُستعاد عبر phpMyAdmin ← Import.
  الملف حساس (فيه بيانات العملاء وتجزئات كلمات المرور)؛ احفظه في مكان آمن ولا ترسله لأحد.
- **ملف JSON للمحتوى:** للنصوص والخطط والأسعار والإعدادات فقط (بلا طلبات ولا مستخدمين ولا كلمات مرور ولا أسرار). مفيد لنقل المحتوى بين موقعين
  أو للتراجع عن تعديلات كبيرة. الاستيراد يعرض أولاً ما سيُضاف ويُعدّل ويُحذف، ولا يطبّق شيئاً قبل تأكيدك، ويُلغى كاملاً إن حدث خطأ.
- **التوصيات:**
  - نزّل نسخة SQL أسبوعياً على الأقل، وقبل أي تعديل كبير أو استيراد.
  - فعّل النسخ الاحتياطي التلقائي في cPanel إن كانت الاستضافة توفّره (JetBackup أو Backup Wizard)، واحتفظ بنسخة خارج الاستضافة.
  - انسخ مجلد `uploads/` أيضاً (الشعارات وصور ومقاطع معرض الأعمال في `uploads/portfolio/`) ومجلد `app/storage/` (مرفقات طلبات الإنتاج)، فهما لا يدخلان في ملف SQL.
  - احتفظ بنسخة من `app/config.php`؛ فيه مفتاح التشفير `APP_KEY`.

### تشخيص المشكلات

- **صفحة «حدث خطأ غير متوقع»:** راجع `app/logs/error.log` من File Manager. للتشخيص المؤقت فقط اجعل `APP_DEBUG` = `true` في `app/config.php` ثم أعدها `false`.
- **التغييرات لا تظهر في الموقع:** امسح ملفات `app/cache/*.cache` (تُمسح تلقائياً عند كل حفظ).
- **فشل رفع الصور:** تأكد أن `uploads/` قابل للكتابة (الصلاحية 755) وأن الملف PNG أو JPEG أو WebP وأصغر من 2MB.
